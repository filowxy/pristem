05 · 动效：之前 / 之后

把鼠标移到两张卡片上对比。左卡刻意关掉过渡，复现打磨前「颜色瞬间跳变」的手感；右卡由打磨层的零特异性基线统一驱动。

之前 · 无过渡

多数 tab、导航、树行原本没有 transition，hover 是硬切。

之后 · 120ms / ease-move

背景、边框、颜色、阴影、按压亮度走同一条曲线；退出更快，不弹跳。

加载态

所有加载指示都在动：三点脉冲、连接指示、骨架微光；只做透明度变化，不位移。

正在思考…

可访问性：应用内的「减弱动效」原本只写 DOM 标志、CSS 从未读取；打磨层补齐了 data-motion / data-pointer / data-living，并让显式「完全」覆盖操作系统的减少动效设置。焦点指示、加载骨架等功能性动画不会被一并关掉。

06 · 无彩黑与连续曲率

原来的「黑」是一组蓝灰：#10141A → #343E4B，蓝通道比红通道高 10–23，越亮越蓝。现在所有中性色 R=G=B，深度只由明度产生；色相只留给语义色、语法色和棱镜。
